# Sunshine-FPS Web Design System（Direction C · R4-B 混合定稿）

## 1. 核心色板与表面层次

| 用途 | Token / 色值 | 说明 |
|---|---|---|
| 主画布背景 | `bg-ink-950` / `#0c0e0d` | 暗 obsidan 深墨底色 |
| 次级板面 | `bg-ink-900` / `#131615` | 弹层、筛选面板、商品陈列基底 |
| 斜切高亮面 | `#151917` / `#161b18` / `#191f1c` | `<DiagonalSurface>` 斜切光影分区 |

| 信号主色 | `text-accent` / `bg-accent` / `#efb829` | 仅用于主 CTA、当前激活态、有限 `限量` 标记；常规商品严禁整卡涂黄 |

## 2. 导航与外壳规范 (`AppShell`)

- **左靠主导航**：Logo 右侧紧邻 `首页`（`/`）与 `全部商品`（`/products`），当前激活页签采用左上与右下角框激活标记 + 琥珀底色淡晕。
- **右上角账户头像菜单**：点击头像打开浮层，收纳 `我的订单`（`/orders`）、`我的库存`（`/items`）、`我的履约单`（`/fulfillments`），已登录态附 `退出`，未登录保留直达 `登录` 入口。
- **下滑自动隐藏**：向下滚动超过 `48px`（delta `> 6px`）顶栏平滑上移收起并收合下拉菜单；向上滚动或回到顶部 `<= 24px` 立即恢复。尊重 `prefers-reduced-motion`。

## 3. 可复用组件边界

- `src/components/ui/*` 保持 shadcn 官方源码，不做业务魔改。
- 品牌自定义包装与几何视觉基元统一放在 `src/components/common/` 与各自域目录下：
  - `DiagonalSurface`：统一首页海报、手风琴展柜、商品卡/展位与活动卡的斜切暗面 + `1px #252b28` SVG 基准线。
  - `LimitedBadge`：统一 `限量` 标记（`slash` `// 限量`、`pill` 描边标签、`compact` 竖轨简标）；常规商品不贴标签。
  - `ActionButton` / `ActionLink`：统一主行动切角按钮（右下 `9px` 斜切 `chamfer-cta`）、次要边框按钮与下划线文字链接。
  - `SectionHeader`：统一分区标题、eyebrow、数量统计与右侧行动入口。

## 4. `/products` R4-B 混合陈列规则

- **筛选控制区**：顶部主搜索框（本地或服务端接入）+ 漏斗按钮触发可折叠筛选面板（含 `商品形态`、`仅看限量`、型号快捷定位与重置）；接口分类 Tab 直接平铺在主工具栏。
- **混合陈列切换**：
  - 处于「默认第 1 页 · 无分类/筛选/搜索词」且商品不少于 4 件时：第 1 件占全宽 `16:7` 主打横幅，第 2–3 件占 `7:5` 非对称双栏，第 4 件及以后自然转入 3 列开放式无外框陈列（末尾不足 3 的倍数左对齐留白）。
  - 处于任意筛选、搜索命中或第 2 页以后：统一切换为对称 3 列网格，便于横向比价与扫读。

## 5. 禁令清单

- 禁用 `GLOSSARY.md` 排除词（`秒杀`、`抢购场`、`品类`、`货品`、`用户`、`通知` 等）。
- 禁止伪造销量、评分或倒计时营销紧迫文案；正文字号不少于 `12px`。
