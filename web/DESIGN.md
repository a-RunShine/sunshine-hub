# Sunshine-FPS Web Design System（Direction C · R4-B 混合定稿）

## 1. 核心色板与字阶

| 用途 | Token / 色值 | 说明 |
|---|---|---|
| 主画布背景 | `bg-ink-950` / `#0c0e0d` | 暗 obsidian 深墨底色 |
| 次级板面 | `bg-ink-900` / `#131615` | 弹层、漏斗筛选面板（`#111513`）、商品展位基底 |
| 斜切高亮面 | `#151917` / `#161b18` / `#191f1c` | `<DiagonalSurface>` 斜切光影分区 |
| 细分割线 | `border-line` / `#252b28` | 1px 发丝级分割线，展位卡仅保留上下分割线、不做四面重边框 |
| 主文字 | `text-foreground` / `#f3efe6` | 骨白标题（普通展位 `20px` / 主打 `34px`）与主价（`22px`–`26px`） |
| 辅助可读文字 | `#c4cac6` | 顶部形态标、开售时间、漏斗分组标题与倒计时前缀（`13px`–`15px`） |
| 次弱文字 | `text-muted` / `#9da39f` | 搜索占位、未激活页签、次要说明 |
| 信号主色 | `text-accent` / `bg-accent` / `#efb829` | 仅用于主 CTA、当前激活态、有限「限量」图标标记；常规商品严禁整卡涂黄 |

## 2. 导航与外壳规范 (`AppShell`)

- **左靠主导航**：Logo 右侧紧邻 `首页`（`/`）与 `全部商品`（`/products`），当前激活页签使用左上与右下角框激活标记 + 琥珀底色淡晕。
- **右上角账户头像菜单**：点击头像打开浮层，收纳 `我的订单`（`/orders`）、`我的库存`（`/items`）、`我的履约单`（`/fulfillments`），已登录态附 `退出`，未登录保留直达 `登录` 入口。
- **下滑自动隐藏**：向下滚动超过 `48px`（delta `> 6px`）顶栏平滑上移收起并同步收合下拉菜单；向上滚动或回到顶部 `<= 24px` 立即恢复。尊重 `prefers-reduced-motion`。

## 3. 可复用组件边界

- `src/components/ui/*` 保持 shadcn 官方源码，不做业务魔改。
- 品牌自定义包装与视觉基元统一放在 `src/components/common/` 与 `src/components/product/`：
  - `DiagonalSurface`：统一首页海报、手风琴展柜、商品展位、主打横幅与活动卡的斜切暗面 + `1px #252b28` SVG 基准线。
  - `ProductKindMark`：仅区分系统闭集商品形态——`VIRTUAL`（数字芯片标 · `虚拟道具`）与 `PHYSICAL`（立体货箱标 · `实体周边`）。遵循 ADR-0014，**商品卡片上不渲染可变货架分类名**（如 `武器皮肤`、`手办`、`服饰`），分类仅保留在顶部栏切换。
  - `LimitedBadge`：统一使用战备切角菱形矢量图标 + `限量` 文案（`slash` 默认标、`pill` 手风琴展开标、`compact` 手风琴收起窄条纯菱形图标）。装饰图标使用 `aria-hidden="true"`，常规商品不贴任何标签。
  - `ActionButton` / `ActionLink`：统一主行动切角按钮（右下 `9px` 斜切 `chamfer-cta`）、次要边框按钮与下划线文字链接。
  - `SectionHeader`：统一分区标题、右侧计数/搜索入口与底部 `border-line` 对齐。
  - `Price`：`default`（普通展位 `22px` 骨白）、`hero`（主打横幅与手风琴展开 `26px`）、`compact`（手风琴收起窄条 `13px #c4cac6`）。

## 4. `/products` R4-B 混合陈列规则

- **筛选控制区**：页头右侧斜切搜索框（移动端 `>= 16px` 防缩放）+ 分类 Tab 左靠 + 计数与「筛选」漏斗按钮右靠。点击漏斗展开可折叠面板（`商品形态`、`售卖属性：仅看限量`、`快捷关键词定位`、`清空全部筛选`）。
- **混合陈列切换**：
  - 默认第 1 页、无任何分类/漏斗/搜索词激活且商品不少于 4 件时：第 1 件占全宽主打横幅，第 2–3 件占 `7:5` 非对称双栏，第 4 件起自然转入 3 列开放式展位网格（末尾不足 3 的倍数左对齐留白）。
  - 任一筛选、搜索词激活或第 2 页以后：统一切换为对称 3 列网格，方便横向对比。
  - 普通展位卡整卡即跳转链接，不再在右下角额外堆砌 `查看详情 →` 小字与重复形态标签。

## 5. 禁令清单

- 禁用 `GLOSSARY.md` 排除词（`秒杀`、`抢购场`、`品类`、`货品`、`用户`、`通知` 等）。
- 禁止伪造销量、评分或倒计时营销紧迫文案；正文与辅助标签字号不少于 `12px`。
