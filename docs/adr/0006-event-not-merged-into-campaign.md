# 运营活动是独立内容，不并入售卖活动

Event（运营活动）有自己的起止时间和正文，可以挂一个折扣 Campaign 的入口，也可以跟商城毫无关系，比如游戏内的周末双倍经验。

不合并的理由很简单：合并之后，运营想发一条纯资讯，也得先建一个"假 Campaign"，而配额、限购、价格这些字段对一个资讯毫无意义。

## Considered Options

- **合并成一个模型**：活动就是 Campaign 的展示层，社区和商城咬合最紧。代价是纯内容型活动被迫携带一堆用不上的售卖字段。
- **完全不相干**：两张表、两套接口，要关联时手工填 ID。实现最省事，但"活动点进去没有商品"这种断链只能靠运营自觉。

## Consequences

Event 上有一个可空的 `campaign_id`。有值时活动页展示"立即前往"，无值时只展示正文。关联是单向的：Campaign 不知道自己被哪个活动引用，需要时反查。
