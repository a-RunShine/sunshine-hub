# 实名放在抢购之前，不放在注册

注册只要用户名和密码。点「立即抢购」时如果还没实名，弹录入表单，填完自动继续原来的抢购动作，不让用户重新点一次。

注册时一次填完更省事，但那等于让每个只是来逛逛的人先交身份证。真实业务不这么干：实名是「参与限量购买」的前置条件，不是「拥有账号」的前置条件。

## Considered Options

- **注册时填**：实现最简单，一个表单搞定。但注册门槛高，而且「为什么看看也要实名」讲不通。
- **下单时填**：和收货地址一起填，少一次打断。但抢购场景下多一步会拖慢流程，而抢购的时间窗口只有几秒。

## Consequences

「未实名」变成一个需要在抢购接口里显式处理的状态，而不是所有接口都默认成立的前提。

实名表单只采集姓名和证件号。早期设计里还要求同时选一个大区，那个概念已经从模型里删掉了，见 ADR-0011。
