# Triage Labels

工程类 skill 说的是两个分类角色加五个状态角色。这两张表把角色映射到本仓库 issue tracker 里实际使用的标签字符串。

**分类角色**

| 角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `bug` | `bug` | 可复现的缺陷 |
| `enhancement` | `enhancement` | 新功能或能力改进 |

**状态角色**

| 角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 待维护者评估 |
| `needs-info` | `needs-info` | 等报告人补信息 |
| `ready-for-agent` | `ready-for-agent` | 已完整定义，可以交给 agent 独立做 |
| `ready-for-human` | `ready-for-human` | 需要人来实现 |
| `wontfix` | `wontfix` | 不做 |

skill 提到某个角色时，用这张表右列对应的标签字符串。

要换命名风格，改右列即可。
